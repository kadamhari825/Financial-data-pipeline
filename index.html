Overview
A production-grade scheduled ETL pipeline pulling daily market data from the Yahoo Finance API, landing raw files in Cloud Storage, transforming and loading into a BigQuery dimensional model, and surfacing business metrics through Looker Studio dashboards. Focus was on idempotent loads, cost-aware query design, and zero-surprises orchestration via Cloud Composer.
Key Engineering Decisions
  • Idempotent daily loads using MERGE statements — safe to re-run on failure without duplicates
  • Partitioned & clustered BigQuery tables (date / symbol) to keep scan costs predictable
  • Parameterised Airflow DAG with full backfill capability for historical loads
  • SLA miss alerting via Cloud Monitoring — on-call notified before users notice

Overview
A streaming lakehouse pipeline ingesting IoT device telemetry via MQTT (HiveMQ broker) into Pub/Sub, processed in near-real-time through Dataflow, and landed into a Delta Lake on GCS. dbt models transform Bronze raw data through Silver cleansed layers into Gold business-level aggregations, surfaced through Looker Studio dashboards.
Key Engineering Decisions
  • Medallion architecture (Bronze → Silver → Gold) for clean, auditable data lineage
  • Schema evolution handled at Bronze — downstream models isolated from upstream changes
  • Dataflow autoscaling configured to handle burst IoT traffic without manual intervention
  • dbt tests on every Gold model — null checks, uniqueness, referential integrity
